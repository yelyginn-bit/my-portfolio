# Брендбук YELYGINN — сводка для моделей

Экспорт из Figma (`p3IBlfFFdnA03s3U7UiarF`), 33 кадра. Этот файл — выжимка текстовых правил
из кадров, чтобы не разбирать картинки заново. **Картинки — визуальный эталон, этот файл — правила.**
Машиночитаемая спецификация — `style-spec-v2.json`.

## Что читать в первую очередь

1) `ELEMENT-BY-ELEMENT RULES.png` — 12 правил сборки (ниже переписаны).
2) `IMPLEMENTATION MAP.png` — токены, дерево компонентов, брейкпоинты.
3) `JSON/V2.png` → `style-spec-v2.json`.
4) Эталоны компонентов: `NAVIGATION`, `BUTTONS + BADGES`, `PROJECT CARDS`, `CASE PAGE`,
   `GLASS + GRADIENT COMPONENTS`, `DARK`, `DATA PANELS`, `SUMMARY`.
5) Остальные (`MONO POSTER SYSTEM`, `REFRACTION + GRAIN`, `TYPE BRUTALISM` и т. п.) — референсы:
   «визуальная калибровка, а не пипетка» (кадр `README`). Цвет из референса не становится токеном.

## Политика цвета

- Основа — 80–90% INK / PAPER. Постоянные акценты интерфейса: VIOLET = цифровое / интерактив,
  SIGNAL ORANGE = тёплое действие / атмосфера.
- **Запрещено как цвет интерфейса:** кислотный лайм, ядовитый жёлто-зелёный, `#D7FF3F`, неон, радуга.
  Лайм встречается в кадрах `PROJECT CARDS` и `DATA PANELS` — это содержимое референса, не токен.
- Красный и синий — только внутри изображений, когда этого требует исходник.

## Брейкпоинты

- ≥ 1200 — 12 колонок, полный технический «хром».
- 768–1199 — 8 колонок, сжатые метаданные.
- < 768 — 4 колонки, стопка в первом экране, горизонтальная лента работ или карточки в одну колонку.
- **Не «причёсывать» брутализм на мобильном: упрощать плотность, а не идентичность.**

## 12 правил сборки (ELEMENT-BY-ELEMENT RULES)

1) **Навигация.** Одна горизонтальная полоса 72–88px. Оболочка может быть матовым стеклом, если за ней
   реальная глубина. Внутри — компактные моно-ссылки, жёсткие разделители, одна главная CTA,
   по желанию — модуль статуса / времени.
2) **Первый экран.** Две колонки: редакционное заявление слева, медиа / композиция справа.
   H1 ≈ 80–110px на десктопе. Маленький фиолетовый моно-кикер. CTA компактная и контрастная.
   Медиа может лежать на широком тёплом / фиолетовом поле с одним осмысленным слоем стекла.
3) **Разделители.** Нейтральные линейки 1px. Разделы привязаны к общим линиям колонок.
   Никаких «плавающих карточек» с SaaS-отступами — разделение архитектурное.
4) **Сетка работ.** Отдельные варианты 2, 3, 4 в ряд. Три элемента — настоящая сетка на 3,
   никогда не 4 колонки с пустой ячейкой. Медиа — основная часть карточки.
5) **Карточка проекта.** Сначала видимая структура 1px. 60–70% медиа, 30–40% метаданные.
   Метка статуса / проекта в левом верхнем углу. Внизу: название, роль / категория, стрелка.
   Стеклянная полоса метаданных — только если за ней есть глубина.
6) **Шапка кейса.** Название начинается близко к верху раздела, без пустой «взлётной полосы».
   Номер / категория — мелким моно, название крупно, роль / год / формат — технические метаданные
   с противоположной стороны.
7) **Медиаблоки.** Изображение от края до края своей рамки. Без необъяснимых чёрных полос.
   Кадрирование осознанное на каждом брейкпоинте.
8) **Шрифт.** Дисплей — тяжёлый гротеск, «сжатый композицией, а не трюками шрифта». Интерфейс —
   моно капсом. Текст — нейтральный гротеск. Не плодить гарнитуры.
9) **Цвет.** См. политику выше.
10) **Текстура.** Зерно / растр / сканлайн / искажение — слоем с умеренной непрозрачностью.
    Текстура поддерживает иерархию и никогда не снижает читаемость.
11) **Скругления.** В основном 0–12px для жёсткой структуры. 20–28px — только для оболочек
    устройств / медиа и стекла. Никакого сплошного мягкого скругления.
12) **Движение.** Микро — 120–220 мс; появление карточек — 300–500 мс. Сдвиги, маски,
    из размытия в резкость, короткие сканлайн-вспышки. Никакого «пружинящего» easing.

## Компоненты — по кадрам

- **Кнопки (BUTTONS + BADGES).** Главная — тёмная, скруглённая, моно капсом со стрелкой `↗`.
  На тёмном фоне главная CTA — SIGNAL ORANGE с подписью INK (кадр `DARK`: «START NOW →», пилюля).
  Второстепенная — прямоугольник с рамкой 1px, моно капсом («SECONDARY / VIEW»).
  Фильтр — прямоугольник с заливкой и тонкой рамкой («FILTER : OPERATOR»).
  Бейджи: ACTIVE — фиолетовая заливка; ONLINE — оранжевый оттенок; ALERT — оранжевая рамка.
  **Пунктирная линия = действие / открытие.**
- **Навигация (NAVIGATION).** Логотип-плашка `Y_` или `YELYGINN_` моно с подчёркиванием-курсором,
  моно-ссылки капсом, главная CTA «START A PROJECT ↗», меню «⋮». Оболочка — стекло со скруглением.
- **Карточки (PROJECT CARDS).** 64% медиа / 36% метаданные, жёсткий кроп, один акцент, видимая рамка,
  явная роль. Метка `PROJECT_01` цветной плашкой в углу медиа, внизу название капсом,
  строка роли моно (`OPERATOR / FILM / LIVE`), фиолетовая стрелка `↗`.
- **Страница кейса (CASE PAGE).** `PROJECT_004` фиолетовым моно; огромное название; справа
  ROLE / FORMAT / YEAR (мелкая моно-метка + значение); медиа во всю ширину в оболочке с подписью
  `FULL-BLEED MEDIA / VIDEO / 16:9`; линейка; две колонки TASK / APPROACH с фиолетовыми моно-метками.
- **Стекло (GLASS + GRADIENT COMPONENTS).** «Стекло — только там, где за ним глубина. Брутальные
  линейки 1px видны вне стекла. Градиенты широкие и размытые, никогда не радуга. Палитра интерфейса —
  ink / paper / violet / orange. Красный или синий из фото — только внутри изображения.»
- **Панели данных (DATA PANELS).** Моно-таблица «ключ // значение» в рамке 1px
  (`NODE : YLG_01 / LOCATION // NIZHNY / ROLE // OPERATOR`). Только с настоящими данными.
- **ДНК сайта (SUMMARY).** Сетка как графика; моно как интерфейс; изображение как доказательство;
  стекло как глубина; мягкие градиентные поля; редакционный масштаб — огромные заголовки
  рядом с крошечными метаданными.
