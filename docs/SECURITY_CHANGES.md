# Изменения безопасности

- OTP: 6 цифр, Node `crypto.randomInt`, TTL 5 минут, максимум 5 попыток, одноразовая выдача сессии.
- Токены: CSPRNG; `Math.random` удалён из токенов и ссылок доступа.
- JWT: не сохраняются в localStorage; серверная сессия — HttpOnly, Secure, SameSite=Lax cookie, клиентский Supabase JWT живёт только в памяти вкладки.
- CSRF: double-submit token для изменяющих запросов.
- Rate limit: формы, запрос OTP, проверка OTP и вход администратора.
- CRM: анонимные insert/update/delete отозваны; события согласия и заявки создаются сервером.
- Галереи: пароль хранится как salted `scrypt`; после проверки выдаётся часовой access-ticket, связанный с одной share-ссылкой и галереей.
- Платежи: сумма и описание определяются сервером; webhook идемпотентен и сверяет локальную попытку.
- Upload: allow-list MIME, предел 50 МБ, безопасный ключ, запрет SVG и path traversal.
- Headers: CSP, HSTS, nosniff, Referrer-Policy, Permissions-Policy и frame-ancestors.
- Ошибки API: наружу не возвращаются stack traces, секреты, ответы Telegram или ошибки БД.
- Распознавание лиц: выключено по умолчанию; production не создаёт embeddings и не отправляет изображения на распознавание. Возможное включение требует отдельной правовой и технической оценки.
