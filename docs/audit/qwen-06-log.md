## Б · разведка рецептов для Claude Code

`docs/audit/fix-recipes-cards.md`. Ни одного файла вёрстки не тронуто; правки
проверялись в браузере через `page.addStyleTag` на текущей сборке, то есть
«стало» из отчёта — измерено, а не предсказано.

Две поправки к вчерашнему отчёту, обе не в пользу храповика Д:

1. «многоточия нет» — неверно. Все `clipY` — это рабочий
   `-webkit-line-clamp: 2` из `src/v3-polish.css:254`, многоточие рисуется
   (кадр). Метрика не различает намеренный clamp и случайную обрезь, поэтому
   42 «нарушителя» — это на самом деле политика «2 строки», а не поломка.
2. Храповик смотрит только верх страницы: `vis()` вычёркивает элементы ниже
   `innerHeight + 4000`. Без выреза `clipY` не 23, а **42** (`offscreen` — те же
   12, `lines`/`overlap`/`clipX` — 0). Строка правки известна, но baseline после
   неё удваивается, поэтому не трогаю: это решение принимающего храповик.

Рецепты: описания — одна цифра `line-clamp: 3` (замерено: бокс 32→49px, высота
карточки не меняется ни на 1440, ни на 390, до строки `small` остаётся 5px, то
есть запас ровно в одну строку); «многоточие по слову» clamp не даёт — на кадре
2× видно «к утверждённо…», слово разрезано, значит резать надо в данных
(`PortfolioSystem.tsx:162`). Заголовок ГРК — `overflow-wrap: anywhere` вместо
`break-word` в `design-system.css:1476`: min-content слова «ГОРЬКОВСКАЯ» при
57.6px = 441.5px, а `break-word` в min-content не участвует, `anywhere` участвует;
замерено правый край 1480 → 1377 при границе панели 1411, `scrollWidth`
остался 1440. Побочка — закрывающая кавычка падает на отдельную строку.
