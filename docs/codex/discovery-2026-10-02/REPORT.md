## Как отправлять свои изменения в GitHub

В терминале из папки проекта:

```sh
cd /Users/urijelygin/Documents/NEW_SITE/yelyginn-v3
git status
git add -u
git diff --cached
git commit -m "Краткое описание изменений"
git push origin main
```

`git add -u` добавляет только изменения уже отслеживаемых файлов. Новые
файлы добавляются отдельно по имени после просмотра: в проекте много
старых неотслеживаемых отчётов, поэтому бездумно добавлять всё не нужно.
GitHub push не публикует сайт на VPS. Проверенный рабочий скрипт:

```sh
ssh -i ~/.ssh/yelyginn_reg_ru root@195.19.20.29 'cd /var/www/yelyginn && ./deploy.sh'
```

Перед запуском проверяется отсутствие незакоммиченных изменений на VPS:
скрипт синхронизирует main, собирает сайт, проверяет HTML и перезапускает PM2.
Рабочий nginx не заменять шаблоном из deploy/: он должен сохранять исправленный
маршрут формы к Vercel. Папка ~/Documents/New_claude/site/ только для чтения.
