# Вход через Telegram-бота — настройка

Код входа присылает твой Telegram-бот (вместо SMS). Работает поверх Supabase
(нужно для общего состояния между вебхуком и сайтом). Без настройки сайт остаётся
в dev-режиме (код показывается на экране).

## ⚠️ Главное про Telegram
Бот **не может первым написать** незнакомому пользователю. Пользователь должен
один раз открыть бота и поделиться номером. После этого бот знает его `chat_id`
и присылает коды мгновенно. Это заложено в флоу (первичная привязка).

## Что нужно
1. **Supabase** подключён (см. `SUPABASE_SETUP.md`), применены `db/schema.sql`
   (там есть таблицы `telegram_links`, `auth_otp`).
2. **Бот** (существующий). Нужны:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather (уже используется для лидов);
   - `TELEGRAM_BOT_USERNAME` — username бота без `@` (для кнопки «открыть бота»);
   - `TELEGRAM_WEBHOOK_SECRET` — любая случайная строка (придумай сам).
3. `SUPABASE_SERVICE_ROLE_KEY` — серверный ключ Supabase (только в env Vercel!).

## Шаги
1. Прописать переменные в **Vercel → Settings → Environment Variables**
   (проект `my-portfolio-github-copy`): `TELEGRAM_BOT_TOKEN`,
   `TELEGRAM_BOT_USERNAME`, `TELEGRAM_WEBHOOK_SECRET`, `SUPABASE_SERVICE_ROLE_KEY`,
   `SUPABASE_URL` (или `VITE_SUPABASE_URL`). Redeploy.
2. **Установить вебхук** — открыть один раз в браузере:
   `https://yelyginn.ru/api/telegram-set-webhook?secret=<TELEGRAM_WEBHOOK_SECRET>`
   Ответ должен содержать `"telegram": { "ok": true }`.
3. Проверить вход: `/account` → ввести имя и телефон → «Войти через Telegram».
   - Первый раз: откроется бот → «Поделиться номером» → на сайте автоматически вход.
   - Далее: бот пришлёт код (или жми «✅ Подтвердить вход» прямо в Telegram).

## Как это устроено (для справки)
- `api/auth-request` — создаёт код/токен, шлёт код в бота или ссылку на привязку.
- `api/telegram-webhook` — принимает `/start`, контакт (привязка), нажатие кнопки.
- `api/auth-verify` — проверка кода. `api/auth-status` — опрос статуса (кнопка/привязка).
- Привязка `телефон↔chat_id` — таблица `telegram_links`. Запросы входа — `auth_otp` (TTL 5 мин).

## Безопасность
- Контакт принимается только если принадлежит отправителю (`contact.user_id == from.id`).
- Вебхук проверяет заголовок-секрет. Коды одноразовые, с истечением.
- `service_role` и токен бота — ТОЛЬКО серверные env, не `VITE_*`.

## Альтернатива (если не заводить Supabase сейчас)
Сайт продолжает работать в dev-режиме: код входа показывается на экране, данные —
в localStorage. Telegram-вход активируется автоматически, как только заданы ключи.
