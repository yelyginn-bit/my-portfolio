# Визуальный аудит сайта — 70 маршрутов, 1440 и 390

Задача 6 смены QWEN-07. Итоговая сборка ветки (`028352c` + правки задачи 5).
Отсортировано по тому, насколько это бросится в глаза владельцу, — а не по
количеству узлов.

## Метод

- `visual-diff capture` — 140 кадров целиком (`fullPage`), плюс отдельные
  кадры-области для того, что подозрительно на уменьшенном просмотре;
- **живой замер метрик, а не глаз**: пустые полосы, горизонтальное переполнение,
  пары «цвет/фон» считаются скриптами (`.night-shots/scratch/empty-bands.mts`,
  `hoverflow.mts`, `fail-share.mts`) — глаз на уменьшенном кадре путается;
- **сверка с живым сайтом** (`https://yelyginn.ru`, только чтение): то, что
  на `localhost` выглядит поломкой, могло быть отсутствием сети.

## 1. Невидимый текст на 49 маршрутах: страницы притворяются тёмными, не переключив тему

**Самое серьёзное за смену.**

```
src/v3-polish.css:6-10
body:has(.v32-home), body:has(.v3-catalog), body:has(.v3-project),
body:has(.v3-editorial-page) { background: #0a0a0a; }
```

Фон `body` становится чернильным, а **токены остаются светлой темы**:
`color` по наследству — тоже `#0a0a0a`. Читается только то, где цвет задан явно
литералом (`v3-polish.css:435-439` отдаёт `#f4f4ef` нескольким классам), остальное
исчезает. Замер на 390 по всем 70 маршрутам:

| что | число |
|---|---|
| узлов с контрастом ниже порога | **419** |
| из них на страницах с таким «тёмным» `body` | **345 (82 %)** |
| буквальных «чернила по чернилам» (цвет == фон) | **158** |
| маршрутов с тёмным `body` без темы | **49 из 70** |

Подтверждено на живом сайте: `/portfolio/sber-arhitektura@390` — 9 узлов INK на
INK, среди них счётчики шагов `01 // 06` … `06 // 06` над каждым видео
(`.v3-project__media-meta span`). В кадре их просто нет.

**Где в коде:** `src/public/V3App.tsx:506` (разметка `.v3-project__media-meta`),
цвет наследуется, правила на `span` нет.

**Предлагаемая правка (два варианта, оба не мои по границам смены):**
1. правильное — `theme: "dark"` в `src/public/routeManifest.ts` для этих
   маршрутов: тогда `data-theme="dark"` ставится при prerender, и `--ds-bg` /
   `--ds-text` сходятся с фоном сами, а строка `background: #0a0a0a` из
   `v3-polish.css` становится ненужной. Мне манифест трогать нельзя (§1.2), и
   это меняет `<html data-theme>` сразу ~49 страниц — решение владельца.
2. временный CSS-костыль — переопределить токены на этих `body`
   (`body:has(.v3-project) { --ds-bg: #0a0a0a; --ds-text: #f2f1ec; … }`), но это
   дубль блока `:root[data-theme="dark"]`, и он разойдётся с настоящим
   переключателем темы.

## 3. Заголовок ГРК рвёт слово посередине

Кадр `.night-shots/audit-shots/home-grk-title.png`: «КОНЦЕРТЫ «СТАНЦИИ МЕТРО
**ГОРЬКОВСК / АЯ»**» — пять строк, последнее слово разрезано.

**Где:** `src/design-system.css:1476` — `overflow-wrap: anywhere` (пришла из
рецепта QWEN-06, чтобы заголовок не вылезал за карточку: min-content слова
«ГОРЬКОВСКАЯ» при 57.6px = 441.5px против 338px колонки).

**Что делать:** слово не влезает целиком ни при каком переносе, поэтому выбор
один из трёх — (а) кегль в узкой колонке (`clamp(2rem, 3.2vw, 3.4rem)` даёт
46.08px и слово встаёт целиком — проверено в QWEN-06 §Б), (б) `hyphens: auto` +
`lang="ru"` (перенос по правилам), (в) оставить разрыв. Это тип-ритм, §0.1
QWEN-06 запрещал мне его трогать — нужно решение владельца.

## 4. Шапка на статических страницах стоит на 14px ниже эталона

Эталон — главная: `.v3-header` = 58px на 390. На `reels`, `photo`,
`calculator`, юридических — 87px при том же `nav.v3-nav` в 58px.

**Где:** `public/site-skin.css:1348` — `header { padding-block: 14px !important }`
и `:1192` — `header { padding-block: 18px !important }`. Правила написаны без
класса до PROMPT-33 и теперь попадают на общий `.v3-header`; у соседних правил
такой guard уже есть (`:not(.v3-header)`, `site-skin.css:1415`).

**Правка:** добавить `:not(.v3-header)` к этим двум правилам — одна строка каждая,
вид легаси-страниц не меняет, шапка встаёт в один уровень с главной. Не сделано
мною только потому, что это меняет пиксели на 22+ маршрутах и требует решения
владельца о «равняем ли».

## 5. Пилот: 4px горизонтального переполнения на 1440, 16px на 390

Единственный маршрут из 70 с переполнением на десктопе. Виновник **не найден**
двумя пробами: ни один узел не выходит за край ни визуальной рамкой
(`getBoundingClientRect`), ни layout-боксом (`offsetLeft + offsetWidth`), при этом
`documentElement.scrollWidth` = 1444. Вероятно, трансформация или скролл-контейнер;
это же состояние тянется с QWEN-05 (было 1444 и 407).

## 6. `/ceny` и `/cvetokorrekciya` — последние большие светлые страницы

§0.4: «весь сайт — тёмный, как главная». Обе страницы светлые; по замеру задачи 5
они **готовы к метке** (0 провалов контраста при включённой в тесте тёмной теме,
129 и 104 измеренных узла). Правка — одна строка на маршрут в манифесте, за
пределами моей смены.

## 7. Форма на главной — белый остров в тёмной странице

Кадр `.night-shots/audit-shots/home-form.png`: блок `.v3-form` белый, остальная
страница чёрная. Это не невидимость (после правки `c30e254` поля и подписи
читаются), а визуальный диссонанс: единственный светлый прямоугольник в нижней
половине главной. Причина та же, что в пункте 1: главная красит себя тёмной
вручную, тема при этом светлая, и `--ds-surface` = белый.

## Что проверено и оказалось чистым

- **Пустых полос нет**: ни на одном из 70 маршрутов нет вертикального участка
  ≥450px (50% экрана) без текста и медиа. Подозрение по уменьшенному кадру
  пилота («Другие услуги» пустая) не подтвердилось.
- **Баннер куки ничего не перекрывает**: на 140 комбинациях ни под одним узлом
  баннера нет кликабельного элемента (`elementFromPoint` в трёх точках).
- **Запрещённой пары «светлое на оранжевом» нет** ни на одном маршруте
  (см. `docs/audit/brandbook-compliance.md`).
- **Пустые видео-блоки на `localhost` — артефакт офлайна**: на живом сайте те же
  iframe 370×208 с постером и кнопкой воспроизведения.
