# Потоки данных yelyginn.ru

Актуально для редакции политики 2.0 от 11.07.2026. Регионы, которые нельзя подтвердить кодом, отмечены как требующие проверки владельцем.

| Поток | Данные | Цель и основание | Регион | Хранение | Отключение | Production |
|---|---|---|---|---|---|---|
| Браузер → REG.RU VPS | HTTP-запрос, IP, user-agent, URL, введённые данные | Работа сайта, безопасность; договор/законный интерес/согласие по форме | Россия | Логи ограничиваются настройками сервера | Нет для работы сайта | Да |
| VPS/API → Supabase | Клиенты, заявки, согласия, заказы, платежные статусы, галереи | Исполнение договора, учёт, доказательство согласия | Требует проверки региона проекта | По срокам политики и закона | Нет для кабинета/CRM после включения | Подготовлено, ключи требуют проверки |
| API → Telegram | Контакт и содержание заявки; OTP; уведомления админу | Коммуникация и подтверждение входа | Иностранная инфраструктура | По правилам Telegram и до удаления сообщения | Relay можно отключить; OTP требует альтернативы | Да |
| VPS → Vercel relay → Telegram | Заявка, IP relay, служебные заголовки | Доставка заявки при недоступности Telegram из VPS | Иностранная инфраструктура | По настройкам Vercel/логам | `LEAD_RELAY_ENABLED=false` после локальной доставки | Да |
| Браузер → Kinescope | IP, user-agent, параметры просмотра видео | Показ портфолио | Российская инфраструктура по заявлению сервиса; договор проверить | По правилам сервиса | Да, убрать embed | Да |
| Браузер → Яндекс Метрика | Обезличенные события и технические сведения, без форм и приватных URL | Аналитика только по согласию | Россия | По настройкам счётчика | Через центр cookies | Да |
| Браузер → Google Analytics | Технические аналитические события | Аналитика только по согласию | Иностранная инфраструктура | По настройкам Google | Через центр cookies/env | Нет |
| API → ЮKassa | ID заказа, рассчитанная сервером сумма, описание, статус | Исполнение договора и платёж | Россия | По правилам провайдера и закону | Да, не подключать оплату | Нет, ключи отсутствуют |
| API → Яндекс Диск | Публичный ключ и путь к файлу | Показ материалов галереи | Россия | По настройкам владельца диска | Да | Да |

Персональные параметры не передаются в аналитику. Аналитика отключена на `/account`, `/admin`, `/g/*`, страницах оплаты и маршрутах с токенами. URL событий очищается до имени публичного раздела.

Внешняя загрузка Google Fonts удалена: интерфейс использует системные шрифты устройства и не обращается к Google до согласия пользователя.

Первичный приём HTTP-запроса выполняется на российском VPS. Это не означает, что последующая обработка во всех подключённых сервисах происходит только в России.
