Политика обработки персональных данных

Документ составлен в соответствии с Федеральным законом от 27.07.2006 N 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их безопасности.

Оператор: Елыгин Юрий Сергеевич

Статус: Плательщик налога на профессиональный доход (самозанятый)

ИНН: 526219298988

ОГРН / ОГРНИП: не применяется

Категории данных: имя, контакты для обратной связи, содержание сообщения из формы, технические данные (cookie/localStorage) для корректной работы сайта.

Цели обработки: обработка заявок, обратная связь с пользователем, коммуникация по проекту, техническое функционирование сайта.

Правовые основания: согласие субъекта персональных данных и иные основания, предусмотренные законодательством РФ.

Трансграничная передача: при использовании внешних сервисов (в том числе мессенджеров и видеоплатформ) возможна передача данных на территорию иностранных государств.

Права субъекта: получение сведений об обработке, уточнение, блокирование, удаление данных, отзыв согласия.

По вопросам обработки персональных данных обратитесь по указанным контактам оператора.
