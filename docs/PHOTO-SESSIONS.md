# Добавить фотосессию (draft PROMPT-52)

Шаблон пока не выпущен. Реальные фотографии в этой задаче не использовались. Ветка по умолчанию содержит пустой каталог: тестовые серии на публичном сайте не появляются.

## Папка съёмки

Положите отобранные JPG/PNG/WebP/AVIF/TIFF и `shoot.md` в одну папку. Имена файлов без подпапок; символические ссылки не принимаются. У каждого фото нужен содержательный alt, обложка — один из этих файлов. Оригиналы остаются на месте; EXIF в производные файлы не переносится. Размеры: 480, 960, 1600 и 2400 px, только применимые без увеличения; небольшой исходник сохраняет свою максимальную ширину. WebP quality82 и AVIF quality50 используют уже установленный sharp, как существующий фото-пайплайн.

`shoot.md` начинается JSON-метаданными между двумя строками `---`. После них — 2–4 абзаца концепции обычным текстом. JSON — намеренно небольшой однозначный формат; YAML-синтаксис сверх JSON не поддерживается.

```text
---
{
  "slug": "nazvanie-serii",
  "title": "Название съёмки",
  "date": "2026-10-21",
  "genre": "предметка",
  "consent": "нет",
  "cover": "01.jpg",
  "photos": [
    {"file": "01.jpg", "alt": "Что изображено в первом кадре"},
    {"file": "02.jpg", "alt": "Что изображено во втором кадре"}
  ]
}
---
Первый абзац — идея и визуальная задача этой конкретной съёмки.

Второй абзац — свет, настроение и то, что объединяет отобранные кадры.
```

Замените дату фактической датой съёмки. Жанр: `портрет`, `студия`, `репортаж` или `предметка`. Согласие модели/правообладателя по умолчанию `нет`; только после подтверждения укажите `да`. Отсутствие «да» останавливает импорт до записи данных/производных изображений. Не ставьте согласие автоматически за другого человека.

## Одна команда для страницы и локальных макетов

```sh
TMPDIR=/tmp/yl41 npm run shoot:add -- "/путь/к/папке" --avito
```

Без `--avito` команда только добавляет данные и обрабатывает фотографии. Отдельная команда макетов, в том числе до согласия на публикацию сайта:

```sh
TMPDIR=/tmp/yl41 npm run shoot:avito -- "/путь/к/папке"
```

Импорт пишет `content/shoots/catalog.json` и производные в `content/shoots/assets/<slug>/`. Это исходные данные вне public, они не обслуживаются сайтом. Перед Vite `prebuild` формирует только согласованную `src/public/shoots.generated.json`. Пререндер копирует только файлы разрешённых записей в dist, создаёт `/fotosessii/<slug>`, карточку на `/photo#fotosessii` и OG из обложки. Sitemap/llms берут маршрут из общего манифеста. `/photo/...` остаётся приватным префиксом: сервер/robots не менялись.

Для отзыва публикации поставьте `consent: false` в записи исходного каталога и выполните чистый `npm run build`: запись, маршрут, карточка, изображения и OG исчезают из dist. Прямой `vite build` не заменяет полный npm-пайплайн. Сама исходная запись и производные остаются вне dist для дальнейшей работы. Изменение локальной сборки не удаляет уже опубликованный материал: если шаблон когда-нибудь будет одобрен, отзыв на сайте требует обычной проверенной выкладки.

Существующий slug и папка макетов не перезаписываются. Для исправления существующей серии сначала явно отредактируйте исходный каталог; автоматического слияния/удаления фотографий скрипт не делает. Если генерация макетов после импорта завершится ошибкой, успешный импорт остаётся на диске — не запускайте импорт повторно с тем же slug, используйте отдельную команду макетов и новый путь вывода.

## Локальные карточки Авито

По умолчанию `_agent-reports/avito-52/<slug>/`: минимальный и журнальный варианты, каждый — обложка и пять слайдов. Inter/Roboto Mono и цвета читаются из существующих файлов сайта. Цены, единицы и минимальный заказ берутся из `pricing.data.ts`: предметка → `photo-product`, репортаж → `photo`, портрет/студия → существующий `photo-studio`. К фиксированной студийной цене слово «от» не приписывается. Цены, скидки, отзывы и обещания не сочиняются. На каждом макете присутствует yelyginn.ru.

Для варианта «до / после» добавьте в JSON только реально существующие пары:

```json
"pairs": [{"before": "01.jpg", "after": "02.jpg", "label": "Подпись к реальной паре"}]
```

Без пар третий вариант пропускается и это записывается в manifest.json. Тестовая серия использует явно подписанную синтетическую пару света, не выдаёт её за ретушь реального клиента. `synthetic: true` — только для учебных картинок: добавляет заметное предупреждение на странице и карточках.

Размер JPEG1280×960 — **предварительный**, не подтверждённый текущими требованиями Авито. Официальный справочник https://support.avito.ru/articles/4351 заблокирован политикой безопасности браузера; обход не использовался. Перед возможной ручной публикацией владелец должен проверить требования в доступном официальном кабинете. В этой задаче ничего на Авито не загружается. Скрипт не выходит в сеть; HTML со встроенными шрифтами и фото сохраняется рядом с JPEG. Все макеты — локальные заготовки. Концепция на слайде сокращается до180символов с многоточием; полный текст остаётся на странице серии.
