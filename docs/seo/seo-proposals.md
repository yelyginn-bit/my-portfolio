# Предложения по текстам для владельца

QWEN-08 §3. **Я ничего здесь не менял в коде** — по §0.5 и §1.3 `title`,
`description`, тексты H1 и альты пишет только владелец. Это список «сейчас →
предлагаю → почему», где правая колонка — поисковый запрос из карты, решённой
владельцем 24.09.

Мерила: `scripts/seo-audit.ts` по пре-рендеренному HTML, 70 индексируемых страниц.
Длины — в символах, как их считает Google (30–65 для `title`, 110–165 для description).

## 1. Бренд в конце title — три варианта на выбор

Сейчас в 70 заголовках смешаны три написания:

| написание | страниц | где |
|---|---|---|
| `YELYGINN` | **56** | портфолио, проекты, блог, услуги-статика, `/calculator` |
| `Yelyginn` | 12 | `/reklamnye-roliki`, `/event-video`, `/reels`, `/photo`, `/video-dlya-marketpleysov`, `/cvetokorrekciya`, `/pryamye-translyacii`, `/content-day` и др. |
| `Юрий Елыгин` | 3 | `/`, `/ceny`, `/contact` |

**Предлагаю:** оставить `| YELYGINN` — он уже большинство, и он же стоит в
`og:site_name`. Исключение — главная: там человек ищет человека, поэтому
`| Юрий Елыгин` уместно, но тогда его надо зафиксировать как единственное
исключение, а не как четвёртый случай. Альтернатива — наоборот, везде `Юрий Елыгин`
(лучше для E-E-A-T и для «видеооператор нижний новгород», где имя = доверие), но
это переписывает 56 заголовков.

Выбор за владельцем; правка механическая и делается за один коммит, потому что
значение в одном месте каждой страницы.

| `/portfolio/sber-arhitektura-teaser` | …Тизер \| YELYGINN (33) | SBER.Архитектура — тизер курса, монтаж \| YELYGINN | то же |

робота — мусор в названии. Предложение: в `<title>` оставить одну черту, в H1 не
трогать (регистр и начертание — вопрос п.4).

## 3. description вне 110–165 — 49 страниц

47 короче нижней границы, 2 длиннее верхней. Короткие — это почти все страницы
проектов и юридические: там description повторяет название без внятного продолжения.

Длинные: `/` (168) и `/pryamye-translyacii` (169) — обрезаются, теряя хвост.

**Что предлагаю:** для проектов — формула «<что это за работа> — <моя роль> ,
<формат/площадка>» на 110–160 знаков, например для
`/portfolio/uchenye-nizhnego`: «Интервью с учёными Нижнего Новгорода: съёмка,
монтаж и цвет. Многосерийный формат для научного проекта.» — **но конкретные
слова о проекте я писать не буду:** в данных есть роль и формат, нет обещания
«многосерийный». Нужна разметка от владельца: что про каждую из 33 работ можно
сказать.

Юридическим страницам description не нужен длинный — там и так всё по делу, но
формально они вне диапазона (85–105). Оставить как есть или расширить — решить
владельцу; для индексации это не критично.

## 4. H1 без ключа на посадочных

| маршрут | H1 сейчас | проблема | предлагаю |
|---|---|---|---|
| `/portfolio` | РАБОТЫ | ни услуги, ни города, ни слова «портфолио» | Портфолио видеосъёмки — Нижний Новгород |
| `/ceny` | Стоимость продакшна | нет города и нет слова «цены» из запроса | Цены на видеосъёмку в Нижнем Новгороде |
| `/about` | ЮРИЙ ЕЛЫГИН | имени достаточно для E-E-A-T, но запрос «видеооператор нижний новгород» не покрыт | Видеооператор Юрий Елыгин — Нижний Новгород |
| `/contact` | ЕСТЬ ЗАДАЧА? РАССКАЖИТЕ | эмоционально верно, но это единственная страница без слова «связаться/Нижний» | Обсудить съёмку в Нижнем Новгороде |
| категории `/portfolio/<кат>` | Операторская работа, События и SDE, Цвет, … | «SDE» и «Цвет» — внутренний жаргон, по нему не ищут | События и фестивали / Монтаж и цветокоррекция / … |

Отдельный случай, **не текст, а разметка:** H1 на `/about` и `/contact` склеен из
двух `<span>` без разделителя — робот читает `ЮРИЙЕЛЫГИН` и `ЕСТЬЗАДАЧА?РАССКАЖИТЕ`
как одно слово (проверено по собранному HTML, `scripts/seo-audit.ts`). Визуально
это две строки. Правка — один пробел или перенос между span'ами, вида не меняет;
сделается вместе с утверждёнными текстами, чтобы не трогать разметку дважды.

## 6. Альты

Ни одна картинка на сайте не осталась вообще без атрибута `alt` — это уже хорошо.
Проблема в другом: **на главной 12 картинок с `alt=""`, и среди них герой-постер
шоурила** (`/v3-assets/hero-showreel-poster.webp`, 1920×1080, `fetchPriority=high`).
Пустой альт говорит роботу «это декорация», а это главное изображение сайта.

На страницах проектов все постеры видео — `alt=""` (4 из 4 на
`/portfolio/sber-arhitektura`). Вариант, который не требует выдумки и берётся из
данных: `alt="<название проекта> — кадр <NN> из <MM>"`. Он не описывает содержание
кадра (я его не вижу и придумывать не буду), но перестаёт быть пустым и не
содержит имён детей — §0.6.

**Имена детей:** ни в одном текущем альте имён нет, и в предложенных формулировках
их тоже не появляется. Проверено по всем 70 страницам.

## 7. Мелочи, которые видел робот, а не человек

- `/llms.txt` на сайте **отсутствует**. Если решать делать — генерировать из
  манифеста и `pricing.data.ts`, а не писать руками: руками он разъедется с
  ценами в течение двух правок.
- `sitemap.xml` — 70 URL, ровно по манифесту, лишних и пропущенных нет. Число
  «77» в промпте устарело. `<lastmod>` не было ни у одной страницы — теперь есть
  (выведен из git по источникам маршрута).
- `robots.txt` закрыл `/admin`, `/account`, `/journal`, `/gallery`, `/g/`,
  `/portfolio/photo`, `/photo/` и ссылается на sitemap — соответствует.
- «ИП» на сайте нет ни разу; статус самозанятого в текстах не противоречив
  (`/payment-terms` говорит «чек самозанятого»).
- `og:image` — один файл `og-cover.jpg` 1200×630 на всех 70 страницах. Формально
  проходит проверку §2.7, но для страниц проектов превью могли бы быть кадрами
  самих работ — это уже контент-решение.
