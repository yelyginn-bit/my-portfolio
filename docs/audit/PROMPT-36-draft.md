# PROMPT-36 — шапка после PROMPT-35, тексты для SEO, разрыв слова и остаток несогласованности

Промпт самодостаточный. Работать по частям, каждая часть — отдельным коммитом,
после каждой — полная проверка из раздела «Проверка».

## Решения владельца — короткие, без них части 2 и 3 не делать

1. **Бренд в конце `<title>`:** `| YELYGINN` везде, кроме главной, где `| Юрий Елыгин`
   (или наоборот — выбрать одно). Сейчас смешаны три написания: 56 / 12 / 3 страницы.
2. **Типографическая шкала ролей:** один уровень — один кегль на всём сайте. Вилку
   «H1 от 48 до 130 px» и «капс или строка» решает владелец; значения — в части 2.
3. **Разрыв слова в заголовке проекта** (часть 1.2): перенос с дефисом (`hyphens: auto`),
   уменьшить кегль, или оставить как есть.
4. **Подкаст клуба предпринимателей** существует или нет (часть 3).
5. **Цены** на «съёмку спектакля», «съёмку подкаста», «имиджевый ролик» — показать или
   закрыть строкой «цена — решает владелец» (часть 3).

## 1. Визуал, который можно чинить без решений владельца

### 1.1 Разрыв слова в H1 страницы проекта — 33 страницы

`src/design-system.css:568`:

```
.v3-project__head h1 { … font: 700 clamp(3.8rem, 9vw, 9rem)/.8 …; text-wrap: balance; overflow-wrap: break-word; }
```

На 1440 и 768 заголовок рвёт слово посередине: «SBER.АРХИТЕ / КТУРА»,
«…ГОРЬКОВСКАЯ / КОНЦЕРТЫ» и ещё 14 маршрутов. Детектор построчных `Range`-rect'ов
(`.night-shots/scratch/accept08.mts`, перенести в `scripts/`) нашёл **78 разрывов**:
16 страниц проектов на 1440 и 768, 4 каталожные карточки h3 на 390, остальное —
повторы. Причина у всех одна: в заголовке одно длинное слово без пробела
(`SBER.Архитектура`), и при кегле 129.6 px оно не влезает в колонку 8fr.

Рецепт зависит от решения владельца (п.3). Если выбран перенос с дефисом:
`overflow-wrap: break-word` → `hyphens: auto` — `lang="ru"` на `<html>` уже есть,
правило уже применено к `h1,h2,h3` в `design-system.css:785` в другом медиа-блоке,
так что приём в кодовой базе существует.

### 1.2 Остаток разрыва в каталоге на 390

## 2. Типографика: свести к одной шкале (после решения владельца)

Замер вычисленных стилей на 1440, 21 страница — в `docs/audit/typography-scale.md`.
Кратко то, что видит глаз:

| уровень | разброс сейчас |
|---|---|
| H1 | 48 / 56 / 69 / 72 / 101 / 104 / 122 / 130 px |
| вес H1 | 700 и 800 (760 уже сведён к 700 в `8788bdd`) |
| регистр H1 | капс на 6 семействах страниц, строка на 4 |
| трекинг H1 | `--ds-track-display` либо `letter-spacing: 0 !important` |
| line-height H1 | от 0.90 до 1.02 |

Источник несогласованности точечно известен и лежит в двух местах:

- `public/site-skin.css:121` — `.site-static :is(header, main, footer) h1 { …
  letter-spacing: 0 !important; text-transform: none !important; }`. Одна строка
  выводит десять статических страниц из брендбукового «дисплей — Bold капсом».
- `src/design-system.css:568` и `:975` — разные `clamp()` для H1 проекта и H1
  сервисной V3-страницы.

Порядок правки: завести токены ролей (`--ds-title-seo`, `--ds-title-work`,
`--ds-title-page`), перевести на них все `font-size`/`line-height`/`letter-spacing`
заголовков, убрать `!important` из `site-skin.css:121`. Проверка — тот же
`style-fingerprint` и `visual-diff`, расхождения ожидаемые и объяснимые построчно.

## 3. Внедрение SEO-текстов (после решения владельца)

`docs/seo/seo-proposals.md` — полный список «маршрут → сейчас → предлагаю → почему».
Что делать после утверждения:

1. Бренд в `<title>` — правится в трёх местах: `index.html` и остальные корневые
   html, `src/public/routeManifest.ts` (поле `seo`), `src/legal/LegalApp.tsx`
   (`page.seo.title`). Проверить, что `scripts/seo-audit.ts` по-прежнему видит
   уникальность: 70 заголовков должны остаться 70 разными.
2. 28 title вне 30–65 знаков и 49 description вне 110–165 — там же.
3. H1 без ключа на `/portfolio`, `/ceny`, `/about`, `/contact` и в категориях —
   это видимый текст, менять только по утверждённой таблице.
4. **Разделённые span'ы без разделителя:** H1 на `/about` робот читает как
   `ЮРИЙЕЛЫГИН`, на `/contact` — `ЕСТЬЗАДАЧА?РАССКАЖИТЕ` (проверено по собранному
   HTML). Правка — пробел или перенос между span'ами, вида не меняет,
   `visual-diff` обязан показать ноль.
5. Альты: 12 картинок главной и все постеры страниц проектов с `alt=""`. Формула,
   которая не требует выдумки и не содержит имён детей:

   содержательный.
6. Пять новых посадочных — по `docs/seo/landing-drafts.md`. Запись в
   `ROUTE_MANIFEST` (`render: "static"`, `theme: "dark"`, `indexable: true`),
   html-файл, при новой позиции — запись в `pricing.data.ts`, иначе
   `scripts/priceGuard.ts` не пропустит расхождение цен.

## 5. Инструменты, которые надо не сломать снова

Три слепые зоны этой ночи были в измерении, а не в вёрстке:

- `tests/dark-static-contrast.test.ts` обходил `main.querySelectorAll("*")`, а
  фиксированная шапка — вне `<main>`. Починено (`178189a`): обход по `document.body`.
  Не возвращать сужение ради зелёного теста.
- `scripts/visual-diff.ts` замазывал медиа **поверх** нарисованного хрома, и правка
  шапки давала «0.000 % идентично» при 798 510 отличающихся пикселях. Починено:
  `protects.json` + команда `chrome`.
- `tests/mobile-audit.test.ts` мерил переполнение как `scrollWidth − clientWidth`
  одной страницей на все 70 маршрутов. Починено (`9baa8b2`): мера «узел правее
  видимого вьюпорта и не спрятан внутренним клиппером», свежий `page` на маршрут.
  Отрицательный контроль: div 430 px в `body` → долг 40 px; то же внутри
  `overflow: hidden` → 0.

Требование к любой следующей правке инструмента: **сначала показать, что он ловит
заведомо сломанное**, и только потом ссылаться на его «ноль».

## Проверка

После каждого коммита:

```
npm run lint && npm test && npm run test:integration && npm run build \
  && npm run test:portfolio && npm run check:budget
npx tsx scripts/style-fingerprint.ts --label до; … ; npx tsx scripts/style-fingerprint.ts --diff до после
npx tsx scripts/visual-diff.ts capture --label до; … ; npx tsx scripts/visual-diff.ts compare --a до --b после
```

Правка для робота (`canonical`, `og:*`, JSON-LD, `alt`, `width/height`, `lang`) —
`visual-diff` обязан показать **ноль** отличий. Правка вида — каждое ожидаемое
расхождение назвать в отчёте кадром и пикселями.

## Чего не делать

- Не менять видимые тексты, `title`, `description`, альты без решений владельца выше.
- Не выдумывать факты, роли, оборудование, метрики и даты. Честные роли: Сбер —
  монтаж трёх роликов и тизер; СИБУР — цвет-доводка под референс; ГРК — монтаж;
  «Горький. Страницы памяти» — только съёмка; «Социальный участковый» — только свет.
- Нигде: материалы Лукойла и 1xBet. Барьер не афишировать. Имен детей в альтах нет.
- «ИП» на сайте быть не должно; статус — самозанятый.
- Лайм — никогда. Светлый текст на оранжевом — никогда (на оранжевом только INK).
  Скругления: 0–12 структура, 20–28 стекло и медиа, 13–19 — запрещённый диапазон.
  Шрифты: Inter и Roboto Mono.
- Не трогать `server/`, `docs/SITE-HANDOFF.md` кроме раздела «Сделано», `package.json`
  кроме регистрации тестов и devDependencies отдельным коммитом.
- Не удалять маршруты, не менять пропорции фото, не трогать шапку главной как эталон.
- Цены — только `src/lib/pricing.data.ts`; расхождение с любым другим списком —
  в отчёт, не в правку.
- Не ослаблять порог теста, чтобы он позеленел. Не мерить переполнение `scrollWidth`
  и не проверять контраст только внутри `<main>`.
