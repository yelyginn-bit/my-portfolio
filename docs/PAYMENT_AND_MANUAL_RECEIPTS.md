# Платежи и ручные чеки НПД

Сайт не формирует чек и не регистрирует доход автоматически.

1. Браузер передаёт только `orderId` и разрешённый способ оплаты.
2. Сервер проверяет сессию, владельца заказа, статус и сумму из БД.
3. Попытка фиксируется в `payment_attempts` со стабильным идемпотентным ключом.
4. Webhook перепроверяет платёж через API провайдера и сверяет provider ID, заказ, сумму, валюту и отсутствие предыдущего зачёта.
   Зачёт выполняет транзакционная RPC `finalize_verified_payment`, блокирующая заказ и попытку до завершения проверки.
5. После подтверждения: `payment_confirmed_at` заполняется, `receipt_status` становится `pending`.
6. Владелец вручную формирует чек в «Мой налог» и отправляет по согласованному контакту.
7. В админке нажимает «Отметить чек как выданный» и при необходимости сохраняет номер/ссылку/способ отправки.

Клиенту показываются только нейтральные статусы. `receipt_admin_comment` остаётся только в административном контуре.
