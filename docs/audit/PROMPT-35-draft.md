## Решения, которые нужны от владельца (короткий список, вверху намеренно)

1. **Тёмная тема — меткой в манифесте или переопределением токенов?** 49 из 70
   страниц сейчас красят `body` чёрным, не переключив тему, и из-за этого 345 из
   419 провалов контраста на 390 (часть — буквальный невидимый текст). Правильный
   ответ — `theme: "dark"` в `routeManifest.ts`; он меняет `<html data-theme>` на
   половине сайта и требует решения.
2. **Заголовок «Концерты «Станции метро Горьковская»»**: сейчас рвёт слово
   посередине («ГОРЬКОВСК / АЯ»). Варианты: кегль в узкой колонке, `hyphens: auto`
   с `lang="ru"`, или оставить разрыв. Это тип-ритм — сам я его не меняю.
3. **Две новые роли токенов** (`--ds-on-dark` = PAPER без учёта темы,
   `--ds-scrim` = INK без учёта темы) — без них ~200 литералов
   (`#f4f4ef`, `rgba(255,255,255,α)`, `rgba(0,0,0,α)`) нельзя перевести на токены
   честно: `var(--ds-text)` перевернёт цвет на светлой теме.
4. **Варианты компонентов в `bb-components.css`**: 7 правил без узлов
   (`.bb-media--portrait`, `.bb-media--square`, `.bb-work-grid--4`,
   `.bb-kicker--muted`, `.bb-case-hero__title`, `.bb-atmosphere--violet::before`).
   Это библиотека или мусор?
5. **Скругления 13–19px** (33 места) — сводить к 12 или к 20, и по какому правилу
   («структура»/«стекло») каждый конкретный случай.

## Часть 1 — тёмная тема как состояние, а не как цвет фона

1) `src/v3-polish.css:6-10`:
   ```
   body:has(.v32-home), body:has(.v3-catalog), body:has(.v3-project),
   body:has(.v3-editorial-page) { background: #0a0a0a; }
   ```
   Заменить на настоящий переключатель: `theme: "dark"` в
   `src/public/routeManifest.ts` для маршрутов этих четырёх семейств
   (49 строк), после чего правило выше удалить целиком — фон даст `--ds-bg`.
2) Проверка после: `npx tsx --test tests/mobile-audit.test.ts` — провалов
   контраста на 390 было 418, из них 345 на этих страницах; цель — ниже 100, и
   ноль узлов «цвет == фон» (было 158). Baseline перегенерировать инструментом.
3) Расширить `tests/dark-static-contrast.test.ts` с 24 маршрутов до всех
   публичных: мерка уже есть, добавляется список. Страницы, где содержимое
   принципиально светлое (если такие останутся), — в явный белый список с
   причиной в комментарии, а не молча пропускать.
4) Инструментальная ловушка, уже сработавшая один раз: на `/ceny` и
   `/cvetokorrekciya` у `body` висит `transition-colors duration-700`
   (`src/index.css`, `@layer base`). Любая мерка «сразу после смены темы» снимает
   середину перехода. Тест гасит переходы (`50f1eba`) — держи этот приём, если
   будешь писать новые мерки.

## Часть 2 — сырые идентификаторы вместо текста

`src/public/V3App.tsx:506`, блок `.v3-project__media-meta`:

```jsx
<a href={`#video-${asset.kinescopeId}`}>#{asset.kinescopeId}</a>
```

На живом сайте это видимая ссылка `#iTRRejvo2n22eTAFy1GCqC` над каждым видео —
6 штук на странице проекта. Якорь нужен (по нему работает `kinescope-embed-behavior`),
подпись — нет. Сделать человекочитаемой (`ВИДЕО 02 // 06` или `asset.title`),
`href` не трогать. Заодно в том же блоке счётчик `01 // 06` — `span` без своего
цвета: после Части 1 он станет видимым сам, проверь кадром.

## Часть 3 — шапка статики ниже эталона на 14px

Эталон — главная: `.v3-header` = 58px на 390. На статике 87px при том же
`nav.v3-nav` в 58px. Причина — легаси-правила без класса, написанные до
PROMPT-33:

```
public/site-skin.css:1192  header { padding-block: 18px !important; }
public/site-skin.css:1348  header { padding-block: 14px !important; }
```

Добавить `:not(.v3-header)` — тот же guard, что уже стоит рядом на `:1415`.
Проверка: `visual-diff` до/после — ожидаемое расхождение ровно на шапке 22
маршрутов, ноль на остальных; `style-fingerprint` — расхождения только у узлов
шапки.

## Чего не делать

- Не менять тексты страниц, факты, состав портфолио; не выдумывать роли и метрики.
- Не трогать пропорции фото и логику вливания PROMPT-33.
- Не поднимать `line-height`/кегль заголовков «чтобы тест прошёл»: если правка
  меняет ритм — это решение владельца (список сверху, п. 2).
- Не возвращать удалённые мёртвые правила `aria-current` с `var(--red)` и
  `.static-cookie-banner`: первое заменено брендовым стилем текущей ссылки,
  второе мертво и в разметке, и в JS.
- Не ослаблять порог `clipY`/контраста ради зелёного теста; baseline — это долг,
  зафиксированный честно, а не настройка.
