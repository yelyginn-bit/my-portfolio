## КОНТЕКСТ
Это премиальный сайт фотографа/видеографа (yelyginn.ru). Уровень визуала —
Apple / Nothing / Leica / Hasselblad: основная тема белая, минимализм, воздух,
выразительная типографика и один акцентный цвет — красный `#fe2c1f`. Тёмный фон
используется точечно для главного видеоэкрана и медиаконтента. Шрифт Inter.

Архитектура **гибридная**: статические HTML-страницы + React-«острова». React
монтируется в `<div id="root"></div>`, точки входа подключены через
`<script type="module" src="/src/.../main.tsx">`. Полная карта — в `SITE-MAP.md`.

## ЗАДАЧА
Сделай цельный, продуманный дизайн ВСЕХ разделов сайта (список ниже). Единый визуальный
язык: сетка, отступы, типографическая шкала, компоненты (кнопки, карточки, инпуты, чипы,
таблицы, модалки, лайтбокс). Все интерактивные элементы — кликабельные и ведут на
реальные адреса (см. «НАВИГАЦИЯ»).

### Разделы для дизайна
1. **Главная `/`** — hero, услуги (`#services`), проекты (`#projects`), «как работаю»,
   цифры доверия, FAQ, CTA-сетка, отзывы (`#testimonials`), форма заявки (`#contact`), футер.
2. **Лендинги услуг** — `/reels`, `/reklamnye-roliki`, `/event-video`,
   `/video-dlya-marketpleysov` (единый шаблон лендинга: hero, выгоды, примеры, цена, CTA).
3. **Портфолио** — `/portfolio` (сетка работ) → `/portfolio/:slug` (страница проекта).
4. **Фото** — `/photo`. **Цены** — `/ceny`.
5. **Калькулятор** — `/calculator` (выбор типа/опций → вилка цены → CTA-заявка).
6. **Кейсы** — `/cases` (карточки) и **Журнал** — `/journal` → `/journal/:slug`.
7. **Кабинет** — `/account` (вход через Telegram-код, профиль, список заказов со статусами).
8. **Клиентская галерея** — `/g/:token`: masonry, лайтбокс (zoom/стрелки), отметки
   (♥/✂/⎙), комментарии, альбомы (чипы + секции), поиск/фильтр, скачивание, 🛒 заказ→оплата.
9. **Админка** — `/admin`: боковое меню/табы (Сводка, Заказы, Клиенты, Заявки, Галереи,
   Платежи, Отзывы, Кейсы, Блог, Прайс, Тарифы, Настройки, Уведомления, История) +
   таблицы, формы, drag&drop загрузка, модалки.
10. **Сквозное**: шапка с навигацией, футер, форма заявки, состояния (загрузка/пусто/ошибка),
    мобильная адаптивность, lightbox, toast-уведомления.

## ОГРАНИЧЕНИЯ (НЕ ЛОМАТЬ — иначе сайт перестанет работать)
1. **Сохраняй `<div id="root"></div>` и теги `<script type="module" src="/src/...main.tsx">`**
   на страницах-островах (`index.html`, `calculator.html`, `account.html`, `admin.html`,
   `gallery.html`, `cases.html`, `journal.html`, `project.html`). Без них React не запустится.
2. **Не меняй URL-адреса и rewrites** (`vercel.json`). Ссылки веди на адреса из «НАВИГАЦИИ»
   (clean URLs без `.html`: `/calculator`, а не `/calculator.html`).
3. **Сохрани якоря-id**: `#services`, `#projects`, `#testimonials`, `#contact`.
4. **Не трогай форму заявки контракт**: поля `name`, `contact`, `message`, POST на `/api/send-form`.
   Можно полностью рестайлить, но имена полей и эндпоинт оставь.
5. **React-разделы** (калькулятор, галерея, кабинет, админка, кейсы, журнал) — это `.tsx` в `src/`.
   Меняй разметку/классы/стили, но **сохраняй data-атрибуты, id, имена обработчиков и структуру
   состояний** (отметки `data-on`, табы, фильтры) — к ним привязана логика.
6. **CSS-переменные бренда** держи: `--red:#fe2c1f`, `--black:#0a0a0a`,
   светлые панели `--panel/--panel-2/--panel-3`, `--gray`, `--line`.
   Белая тема — основная, красный — главный акцент, чёрный — контраст и медиасекции.
7. Стили — Tailwind (подключён) + `src/index.css`. Шрифт Inter. Адаптив: 320 → 1440px.
8. Не подключай внешние CDN/шрифты-фетчи там, где их нет (CSP/офлайн-сборка); инлайнь ассеты.
